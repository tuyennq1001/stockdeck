What's New in StockDeck 1.1.12

  • Text Editing & Select All Shortcuts: Configured standard macOS Main Menu (Edit menu) enabling Command + A (⌘A), Copy (⌘C), Paste (⌘V), Cut (⌘X), and Undo (⌘Z) across all text inputs.
  • PC / Windows Keyboard Support: Added fallback support for Control + A (Ctrl+A) so users on external PC keyboards or with muscle memory can Select All text seamlessly.
  • Search Sheet Auto-Focus: Improved focus handling and text navigation in Watchlist and Symbol search sheets.
