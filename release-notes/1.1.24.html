What's New in StockDeck 1.1.24

  • Dedicated Mode Rail Tabs: Reorganized workspace navigation into 5 clean tabs along the left rail: Index, Superchart, News, AI Insight, and Settings.
  • Chrome Folder Tab Design: Redesigned vertical tabs with Chrome-inspired folder styling — the active tab connects seamlessly with the workspace background, while inactive tabs feature smooth hover highlights and elegant hairline dividers.
  • Keyboard Shortcuts (⌘1 – ⌘5): Switch between modes instantly using global shortcuts: ⌘1 Index, ⌘2 Superchart, ⌘3 News, ⌘4 AI Insight, and ⌘5 Settings.
  • Refined Sidebar Experience: Sidebar navigation is now focused on Watchlists, Portfolios, and Utilities within the Index tab, giving full-width canvas to charts, news, insights, and settings.
