Responsive Positions Table & Native Currency Precision

  • Full-Width Responsive Positions Table: The portfolio positions table now responsively stretches to 100% of the screen width with dynamic column sizing, eliminating wasted side space and keeping stock names cleanly on single lines.
  • Native Currency Consistency: Cost basis, Average Cost, Market Value, and Position P&L now strictly preserve each asset's native currency symbol (₫, $, ¥, €), keeping position details clear and consistent.
  • Automatic Weight Sorting: Portfolio positions now default to sorting by weight/market value descending. Newly added assets are automatically placed in their sorted position by weight.
  • Performance & Benchmarks: Enhanced money-weighted return (XIRR) tracking and period change calculations.
